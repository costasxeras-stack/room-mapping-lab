# 0001: LiteAPI's mapping as the reference, not the truth

**Status:** accepted, 0.1.0

## Context

There is no hand-labelled set. LiteAPI's mappedRoomId is the best available answer.

## Decision

Score methods on agreement with LiteAPI, call it agreement everywhere, and show disagreements as the most useful rows for a mapping team.

## Tradeoff

- Cannot say which side is wrong in a disagreement
- Honest, and the disagreements become an audit list
